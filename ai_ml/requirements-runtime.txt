# Runtime-only dependencies for the deployed backend.
#
# This is deliberately a SEPARATE, smaller file from ai_ml/requirements.txt.
# Installing the full training file (which includes transformers, and
# therefore torch) into the SAME environment as the deployed app causes
# spaCy's ML backend (thinc) to auto-detect and import torch purely because
# it's present — even though predict_ml() never imports it at runtime when
# no trained checkpoint exists. Measured impact: ~780MB of extra memory
# (presidio_analyzer import alone: 888MB with torch installed in the venv
# vs 105MB without it) — enough by itself to exceed Render's 512MB free-tier
# limit on startup, before serving a single request. See DEPLOYMENT.md for
# the full incident writeup.
#
#   pip install -r backend/requirements.txt -r ai_ml/requirements-runtime.txt
#   python -m spacy download en_core_web_sm

presidio-analyzer>=2.2
presidio-anonymizer>=2.2
spacy>=3.7
